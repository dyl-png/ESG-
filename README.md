## 🎯 研究问题

**核心命题**：在A股光伏行业，企业的ESG（环境、社会、治理）表现是否与股价表现存在相关性？

**研究假设**：
- H1：研发投入占比与股价涨跌幅呈正相关
- H2：碳排放强度与股价涨跌幅呈负相关
- H3：ESG综合评级与股价涨跌幅呈正相关
- H4：员工培训时长与股价涨跌幅呈正相关
- H5：独立董事比例与股价涨跌幅呈正相关

---

## 📈 核心发现

### 2024年（行业下行期）

| ESG指标 | Pearson r | p值 | 结论 |
|:---|:---:|:---:|:---|
| **研发投入占比** | **+0.810** | **0.015** | ✅ 强正相关，统计显著 |
| **碳排放强度** | **-0.777** | **0.023** | ✅ 强负相关，统计显著 |
| **ESG评级数值** | **+0.738** | **0.036** | ✅ 中等正相关，统计显著 |
| **员工培训时长** | **+0.772** | **0.025** | ✅ 强正相关，统计显著 |
| 独立董事比例 | +0.616 | 0.104 | ❌ 不显著 |

### 2025年（行业复苏期）

| ESG指标 | Pearson r | p值 | 结论 |
|:---|:---:|:---:|:---|
| **研发投入占比** | **+0.756** | **0.030** | ✅ 仍显著，跨周期稳健 |
| 碳排放强度 | -0.700 | 0.053 | ⚠️ 边际显著 |
| ESG评级数值 | +0.680 | 0.064 | ⚠️ 边际显著 |
| 员工培训时长 | +0.605 | 0.112 | ❌ 不显著 |
| 独立董事比例 | +0.491 | 0.217 | ❌ 不显著 |

### 跨周期稳健性结论

> **研发投入占比是唯一在"行业下行期"和"行业复苏期"两种截然不同的市场环境中均保持统计显著性的ESG指标**，展现出最强的跨周期稳健性。

## 📚 研究方法

### 1. 样本选择
- **行业**：A股光伏设备板块（申万三级行业分类）
- **公司**：8家代表性上市公司（按市值+营收筛选）
- **时间**：2023-2024年年报ESG数据 + 2024-2025年股价数据

### 2. 变量定义

| 变量类型 | 具体指标 | 数据来源 |
|:---|:---|:---|
| **被解释变量** | 2024/2025年全年股价涨跌幅（%） | Tushare/东方财富（前复权） |
| **解释变量-E** | 碳排放强度（吨CO₂/万元营收） | 年报"环境与社会责任"章节 |
| **解释变量-S** | 研发投入占比（%） | 年报财务报表 |
| **解释变量-S** | 员工培训时长（小时/人） | 年报社会责任章节 |
| **解释变量-G** | 独立董事比例（%） | 年报公司治理章节 |
| **解释变量-综合** | ESG评级（AA/A/BBB） | 华证指数/商道融绿 |

### 3. 分析方法
- **Pearson相关系数**：衡量线性相关程度
- **双尾t检验**：判断相关性是否统计显著
- **显著性水平**：p < 0.05为显著，p < 0.01为极显著

### 4. 研究设计
- **横截面分析**：8家公司在同一时点的ESG与股价对比
- **滞后一期（Lag=1）**：第T年ESG数据 → 解释第T+1年股价表现
- **跨周期稳健性检验**：2024年（下行期）vs 2025年（复苏期）对比

---

## ⚠️ 研究局限

1. **样本量较小**（n=8），统计检验力有限，结果需谨慎外推
2. **ESG数据口径**：碳排放范围1/2/3的界定在不同公司间可能存在差异
3. **股价数据估算**：2025年数据基于公开信息整理，精确度不及封盘数据
4. **相关≠因果**：横截面分析无法确定因果方向
5. **行业特异性**：结论可能不适用于其他行业
